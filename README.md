# WINDOW V1.1 · Minimal UI

保留 V1.1 功能，界面回归 V1.0 极简雨窗。修改前版本已备份为同级目录的 `WINDOW-before-ui-return-*.zip`。目录不是 Git 仓库，本次从完整 V1.0 baseline 压缩包复用了原版 UI 样式，没有整体回退项目。

## 启动

在本目录执行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

打开 http://localhost:8080/ 。也可使用 `start.command`。无新依赖，全部素材在本地。

## 操作

按住鼠标拖动擦雾。每笔擦痕停留约 20 秒，随后约 8 秒恢复。右下角依次为：

1. 场景：城市 / 森林 / 海边，以及本机 JPG、PNG、WebP 上传。
2. 雨量：小雨 / 中雨 / 大雨。
3. 声音：雨声、城市声、风声独立音量，总音量及开启 / 静音。
4. 玻璃：20–160 px 画笔、恢复暂停 / 继续、重置雾气。
5. 全屏：进入 / 退出浏览器全屏。

一次只打开一个浮层；点击外部或按 Esc 关闭。默认无浮层、无声音。暂停恢复时仍可擦拭；场景切换不清除擦痕或重置声音。自定义图片仅在浏览器内读取，刷新后不保留。

## 本次修改范围

- `index.html`：恢复原版界面结构，加入五入口与四个紧凑浮层，移除桌面 / 物件 / 抽屉。
- `style.css`：直接复用 V1.0 字体、间距、品牌与悬浮栏样式，补充统一浮层样式。
- `js/ui.js`：复用 V1.1 控制器接口，将事件绑定迁移至浮层。
- `js/config.js`：仅将画布展示尺寸恢复至 1920×1080，并恢复原版城市调色配置；场景加载算法未改。
- `js/main.js`：仅移除不再展示的室内物件图片等待逻辑。
- `js/fog.js`、`js/rain.js`、`js/audio.js`、`js/state.js`、`vendor/raindrop-fx.js`：哈希验证与修改前完全一致。

原桌面图片保留在 assets 中，但不加载或展示。素材和开源许可见 `THIRD_PARTY.md`。以 PC 16:9 为主，非 16:9 窗口保留留边；较矮场景中的浮层可以内部滚动，不超出画面。Safari / Firefox 未逐一验证，嵌入浏览器可能限制全屏。
